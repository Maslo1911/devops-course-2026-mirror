# Заметки: VS Code vs терминал для работы с Git

## Что удобно в VS Code

1. **Визуальный diff и staging по кускам (hunks)** — можно кликом добавлять в индекс не весь файл, а отдельные строки или блоки изменений, сразу видя подсвеченные добавления и удаления рядом друг с другом.

2. **Встроенная история и blame** — по клику на файл можно посмотреть, кто и когда менял конкретную строку, а также пролистать историю коммитов без запоминания хэшей и флагов `git log`.

3. **Разрешение конфликтов слияния через интерфейс** — при конфликте VS Code показывает кнопки «Accept Current / Incoming / Both», что заметно быстрее и понятнее, чем вручную редактировать маркеры `<<<<<<<` в текстовом редакторе.

## Что удобнее делать в терминале

- **Сложные и нестандартные операции**: интерактивный rebase (`git rebase -i`), cherry-pick нескольких коммитов, работа с submodules, тонкая настройка `git config` или написание алиасов — здесь терминал даёт полный контроль и предсказуемость, тогда как GUI часто скрывает часть флагов или упрощает сценарий до примитивного.
